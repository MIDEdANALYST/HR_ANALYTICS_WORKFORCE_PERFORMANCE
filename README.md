# HR Analytics – Workforce Performance Dashboard

## Project Overview
An interactive Excel dashboard developed to analyse workforce data, monitor employee attrition, and understand key HR metrics.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Pivot Tables & Pivot Charts
- Excel Formulas
- Slicers & Timelines
- Data Visualisation

## Key Metrics
- Total Workforce
- Active Employees
- Employee Attrition
- Employee Tenure
- Hiring & Exit Trends

## Project Files
- `HR_Analytics_Dashboard.xlsx` – Complete Excel workbook.
- `Dashboard_Preview.png` – Dashboard visual preview.

## Objective
To transform employee data into meaningful insights that support workforce analysis and informed HR decisions.
